# WebsiteComparer Roadmap

Planned future enhancements include:

- Authentication support for Azure AD, cookie-based sessions, and form login flows
- Accessibility audits with WCAG-focused checks
- Lighthouse integration for performance and best-practice comparisons
- Side-by-side performance telemetry and Core Web Vitals tracking
- API contract and payload comparison workflows
- PDF report generation for stakeholder distribution
- Richer diff categorization for templates, navigation, and media assets
- Parallel crawl execution with configurable throttling
